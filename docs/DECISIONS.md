| 2026-11-20 | Bearbeiten-Befehle (⌘C/⌘V/⌘Z …) werden an das fokussierte Steuerelement weitergeleitet | Die native macOS-Menüleiste fängt diese Kürzel ab, bevor TextBox/Editor sie sehen. |
| 2026-11-20 | Avalonia-Build-Telemetrie (`AvaloniaStats` aus Avalonia.BuildServices) per leerem Target in `Directory.Build.targets` abgeschaltet | Projektregel „keine Telemetrie“; der Collector-Prozess blockierte außerdem einen Build. |
| 2026-11-20 | Pfade vor `dotnet`-Aufrufen und vor dem Laden mit `RealPath.Resolve` auflösen | NuGet-Restore scheitert („file already exists“), wenn eine Solution über einen Link-Pfad (macOS `/var` → `/private/var`) geöffnet wird. |
| 2026-11-20 | Eigener `ViewLocator` (nicht recycelnd) statt XAML-DataTemplates für Dock-Inhalte | Avalonias `DataTemplate.Build(data, existing)` gibt das übergebene Steuerelement zurück; Dock reicht beim Tab-Wechsel das alte weiter, dadurch zeigte ein neuer Tab die vorherige Ansicht. |
| 2026-11-20 | Ein einziges `NativeMenu`-Objekt pro Fenster, nur Einträge werden ersetzt | Avalonia.Native wirft „The menu being updated does not match“, wenn ein Fenster ein neues NativeMenu bekommt. |
| 2026-11-20 | Diagnosen: Compiler über `SemanticModel.GetDiagnostics`, Analyzer (später StyleCop) über `CompilationWithAnalyzers` pro Dokument | Pro Datei schnell genug für < 1 s; Solution-weite Analyse läuft nach dem Laden im Hintergrund. |

Provider, die fehlschlagen oder > 3 s brauchen, werden übersprungen. |

| 2026-11-20 | Completion-Commit wird auf den inzwischen weitergetippten Text abgebildet (`CompletionEditMapper`) | Roslyn berechnet die Änderung für den Text beim Öffnen der Liste; AvaloniaEdit filtert danach clientseitig weiter. |
| 2026-11-20 | Projekt-/Solution-Operationen über die `dotnet`-CLI (`new`, `sln add/remove`, `add reference`, `add package`) statt eigener csproj-Manipulation; nur Eigenschaften werden direkt im XML geändert | Die CLI kennt alle SDK-Sonderfälle (slnx, zentrale Paketversionen, Frameworks); Eigenschaften brauchen Formatierungserhalt, den `ProjectFile` mit `LoadOptions.PreserveWhitespace` liefert. |
| 2026-11-20 | Vorlagen aus `dotnet new list` statt fester Liste | Zeigt genau die beim Nutzer installierten Vorlagen, auch eigene. |
